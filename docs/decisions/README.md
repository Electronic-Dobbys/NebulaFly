# Architecture Decision Records

Crear un ADR por decisión arquitectónica importante.

Ejemplo:

```text
0001-typescript-and-vite.md
0002-raymarching-vs-sparse-volume.md
0003-starless-optional-python-backend.md
```

Plantilla:

```markdown
# ADR NNNN — Título

## Status
Proposed / Accepted / Rejected / Superseded

## Context

## Options Considered

## Decision

## Evidence

## Consequences

## Revisit Conditions
```
