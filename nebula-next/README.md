# nebula-next

Área de desarrollo de la nueva implementación.

No se obliga ninguna tecnología inicial.

El agente debe primero:

1. medir el baseline;
2. comparar arquitecturas;
3. seleccionar un enfoque;
4. crear aquí la implementación ganadora o los prototipos necesarios.

La estructura `src/` es sugerida y puede refinarse mediante ADR.
